# PRO Agent Operating Platform

Internal operating system for a Dubai-first PRO / company-administration services business.

**Status:** requirements baseline (v0.1) — not approved for production build. See `docs/requirements/`.

## Governing documents
- [BRD v0.1](docs/requirements/BRD_PRO_Agent_Operating_Platform_v0.1.md) — business scope, guardrails, decision gates
- [PRD v0.1](docs/requirements/PRD_PRO_Agent_Operating_Platform_v0.1.md) — technical requirements, data model, security policy

## Founder-friendly operating contract
This project follows a strict human-approval model: no production access, spend, real customer data, or deployment happens without explicit founder approval. See BRD §02 and PRD §10–11.

## Phase gate
Currently at **P00 — Decision gates and scope**. No application code ships until P00 approvals (legal, budget, pilot economics) are recorded. See PRD §13 for the file structure this repo will grow into.
